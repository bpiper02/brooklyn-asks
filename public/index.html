METHOD / NOTES

What this record does — and does not — claim

01

Official source first

Core request and agency-response records come from NYC’s Register of Community Board Budget Requests. We retain tracking codes and publication dates.

02

Response is not delivery

A supportive agency response is not proof that a project was funded, built, or completed. Published response and independently verified outcome remain separate facts.

03

Recurring is conservative

A recurring theme means the same board requested the same normalized request type in multiple fiscal years. Exact-project matching needs stronger location or description evidence.
