FEEDBACK / CONTRIBUTE

See something wrong? Help make the record better.

Brooklyn Asks is open source and source-first. Corrections should point back to an official record whenever possible.

01

Leave feedback

Report a wrong label, broken source, missing request, confusing interaction, or other issue.

Open a GitHub issue ↗
02

Contribute code or data

Fork the repository, preserve provenance, and submit a pull request. Historical additions should include board, fiscal year, request, agency, source URL, and source date.

View repository ↗
03

Star / follow the project

If the work is useful, starring the repository helps other civic-data people find it and gives the project a visible public trail.

Star on GitHub ↗
04

Contact the maintainer

For collaboration, research, press, or institutional use, contact the maintainer through the public GitHub profile.

CONTRIBUTION STANDARD

Evidence over assertion.

Keep the source

Every added factual record should retain a direct source URL and a date or fiscal-year context.

Separate fact from inference

Agency responses, derived labels, repeated-theme matches, and real-world outcomes are different fields.

Correct publicly

Material corrections should be visible in Git history or issues rather than silently overwritten without explanation.
